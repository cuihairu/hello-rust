# Language Core

Ownership, borrowing, lifetimes, traits, generics, enums and pattern matching, error handling — the core mechanisms that set Rust apart from other languages, and the foundation for reading any Rust code.

- Ownership and Move Semantics — the three rules, stack/heap and move, Copy types.
- Borrowing and References — shared and mutable borrows, the borrowing rules, NLL.
- Slices and &str — `&[T]`, string slices, deref coercion.
- Lifetimes — `'a` annotations, elision rules, `'static`.
- Enums and Pattern Matching — data-carrying enum variants, Option, match exhaustiveness.
- Traits and Implementations — trait definitions, default methods, an intro to trait bounds.
- Generics and Monomorphization — generic functions and structs, monomorphization.
- Error Handling — Option and Result, the `?` operator, panic boundaries.
